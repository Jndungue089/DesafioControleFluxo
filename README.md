# Desafio de Controle de Fluxo

Exercício **Java** (DIO): lê dois números inteiros e imprime a contagem entre eles. Se o segundo for menor que o primeiro, a validação falha e é mostrada a mensagem *"O segundo parâmetro deve ser maior que o primeiro"*.

Praticam-se `for`, validação de parâmetros e tratamento de exceções (`ParametrosInvalidosException`).

```bash
javac src/*.java
java -cp src Contador
```
